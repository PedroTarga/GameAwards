# Game Awards

Este site é um trabalho desenvolvido por **Pedro Targa, Rafael Dantonio e João Pedro** como parte do nosso projeto de Desenvolvimento Web. O projeto apresenta jogos indicados ao Game Awards, organizados por categoria, com busca, destaques e páginas de detalhes.

## Funcionalidades

- Listagem, busca e filtros de jogos por categoria.
- Jogos em destaque e página de detalhes.
- Painel administrativo para gerenciar jogos e categorias.
- Autenticação e persistência de dados com Supabase.

## Tecnologias

- HTML, CSS e JavaScript.
- Supabase (banco de dados e autenticação).
